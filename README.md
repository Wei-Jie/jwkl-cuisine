# 🥘 小灶私廚 - 訂單與營收管理系統 (v2.0 GAS 版)

「小灶私廚」專為微型餐飲、私廚與小規模手工工作室設計，是一套無需維護伺服器、架構極輕量的「無伺服器 (Serverless)」內部管理系統。

本系統 2.0 版已全面升級為 **Google Apps Script (GAS) 中介架構**，達成「免頻繁登入、多人同步防衝突、效能極速」的操作體驗。

---

## ✨ 核心模組與功能

### 1. 📝 新增訂單 (`order-new.js`)
- **UUID 唯一識別碼**：每筆訂單與明細皆自動生成 UUID，徹底解決傳統行號位移導致的資料覆蓋問題。
- **並發寫入技術**：採用 `Promise.all` 同時發送主檔與多筆明細，儲存速度提升 2 倍以上。
- **即時試算**：自動計算小計與總額，支援秤重品項留白等日後結算。

### 2. 📅 排單管理 (`order-list.js`)
- **智慧明細編輯**：點擊「📝」即可進入明細視窗，支援隨時增編修或調整秤重金額。
- **批量狀態變更**：一鍵勾選多筆訂單進行「已完成」、「已出貨」狀態同步。
- **自動連鎖刪除**：若刪除某單最後一筆明細，系統會自動偵測並同步刪除訂單主檔，保持資料潔淨。

### 3. 📊 營收統計 (`revenue.js`)
- **智能成本演算法**：
  - 支援「**百分比成本**」（如 45%）：自動以「實際成交小計」計算成本，精準解決秤重商品因重量不一導致的毛利誤差。
  - 支援「**固定成本**」：依數量乘以單品本錢。
- **容錯除塵器 (Trim Helper)**：自動過濾試算表欄位名稱或品項名稱中不小心多打的隱形空白。
- **財務總覽**：統計訂單數、總營收、已收款、未收款與預計毛利。

### 4. 🧾 菜單與 💸 支出管理
- 完整的 CRUD 介面，直接在網頁端修改菜單價格或新增採買支出，不再需要手動開啟 Excel/Google Sheets。

---

## 🛠️ 技術架構

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3.
- **Backend API:** Google Apps Script (GAS) - 擔任中介層，封裝複雜的 Sheets 操作。
- **Database:** Google Sheets (以 UUID 作為主要索引值)。
- **Performance:** 全面導入非同步並發 (Asynchronous Concurrency) 請求。

## 🚀 快速開始 (Quick Start)

### 1. 啟動系統
在專案根目錄雙擊執行 `start.bat`，系統將自動開啟瀏覽器並載入管理介面。

### 2. 管理員配置 (`js/config.js`)
目前系統已串接專屬 GAS 端點，若需更換資料表，請修改 `GAS_URL`：
```javascript
const CONFIG = {
    GAS_URL: 'https://script.google.com/macros/s/.../exec',
    SHEETS: {
        ORDER_MAIN: '訂單主檔',
        SCHEDULE: '排單表',
        MENU: '菜單',
        EXPENSES: '支出紀錄'
    }
};
```

### 3. 強制刷新說明
由於瀏覽器快取機制，若更新程式後發現數據未準確顯示，請按下 **`Ctrl + F5`** 強制重新讀取最新腳本。
