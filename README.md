# 🥘 小灶私廚 - 訂單與營收管理系統 (v2.1 資安升級版)

「小灶私廚」專為微型餐飲、私廚與小規模手工工作室設計，是一套無需維護伺服器、架構極輕量的「無伺服器 (Serverless)」管理系統。

本系統 2.1 版已全面升級為 **內外分離式架構**，提供給客戶優雅的點餐選單，同時擁有「私鑰密碼防護」、「防止公式注入」與「LINE 即時推播」的商業級別安全防線。

---

## ✨ 核心模組與功能

### 1. 🛍️ 客戶自助點餐 (`menu.html` & `order.html`) [v2.1 新增]
- **動態圖文網頁**：客戶不需登入即可滑動查閱菜單、過濾分類，具有精美 UI。
- **免帳號預約送出**：直接送出訂單預約，無縫寫入後台緩衝區。
- **LINE 機器人連動**：收到新訂單的瞬間，老闆的手機 LINE 會立刻收到「小灶私廚預約通知」。

### 2. 🛡️ 審核預約與資安防護 (`Backend.gs` & `pending-orders.js`) [v2.1 新增]
- **預約轉正機制**：老闆看過客人留的預約單後，一鍵按下「✅ 核准」，系統將自動產生 UUID、分配正式訂單尾號，並無縫拆分成明細寫入排單系統。
- **後台防護鎖與防毒**：登入老闆後台必須提供自訂密碼，且徹底封堵了客人透過訂單惡意輸入 `=公式` (Formula Injection) 破壞試算表的手段。

### 3. 📝 訂單與排單管理 (`order-new.js` & `order-list.js`)
- **極速記憶體寫入**：利用 Google Apps Script 的全記憶體批次取代演算法，大幅減少 API 呼叫，寫入/刪除百筆資料也能一秒完成。
- **狀態管理**：一鍵勾選切換「備料中」、「製作中」、「已出貨」。
- **彈性秤重計費**：支援無固定單價（如 1.4*重量）之商品，可留白數量，日後再補上最終報價。

### 4. 📊 營收統計 (`revenue.js`)
- **智能成本演算法**：
  - 支援「**百分比成本**」（如 45%）：自動以「實際成交小計」計算成本，精準解決秤重商品因重量不一導致的毛利誤差。
- **財務總覽**：統計指定期間的訂單數、總營收、已收款與預計淨利。

## 🛠️ 技術架構

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3. (含 XSS 渲染防護)
- **Backend API:** Google Apps Script (GAS) 作為安全中介層與發信端點。
- **Database:** Google Sheets 分割「暫存特區」與「主力資料庫」。
- **Security:** 密碼 Token 檢核、`sanitizeData` 公式清洗、`escapeHtml` 前端跳脫。

## 🚀 快速開始 (Quick Start)

### 1. 啟動系統
在專案根目錄雙擊執行 `start.bat`（或推上 GitHub Pages），您可獲得三種不同用途的網址：
- `index.html`：老闆專用後台（需密碼解鎖）。
- `menu.html`：給客戶看的精美菜單展示。
- `order.html`：給客戶填寫的手機預約單。

### 2. 環境變數配置
升級 2.1 後，您**必須**至 Google Apps Script 佈署頁面的 **專案設定 > 指令碼屬性** 新增以下三把鑰匙才能運作：
- `ADMIN_TOKEN`: 登入後台的密碼字串。
- `LINE_ACCESS_TOKEN`: LINE Notify 的授權碼。
- `LINE_USER_ID`: 接收通知的對象。

### 3. 設定綁定 (`js/config.js`)
確保您的 `GAS_URL` 輸入正確：
```javascript
const CONFIG = {
    GAS_URL: 'https://script.google.com/macros/s/.../exec',
    SHEETS: {
        PENDING: '客戶預約單', // v2.1 擴充
        ORDER_MAIN: '訂單主檔',
        SCHEDULE: '排單表',
        MENU: '菜單',
        EXPENSES: '支出紀錄'
    }
};
```
