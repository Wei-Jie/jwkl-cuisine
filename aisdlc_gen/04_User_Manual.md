# 04. 使用者操作手冊 (User Manual)

**讓您隨處登入就能管好小灶私廚的終極兵器。**

## 🚀 入門須知
- 我們的系統已經升級至 **GAS 零授權中介模式**：這代表您不需像以前一樣擔心憑證過期或要常常重新認證，點開網頁即可馬上開始享受光速接單！
- 為了確保畫面總是能夠載入最完美的防呆除錯修補，**若遇到卡頓或畫面問題，請勇敢按下「Ctrl + F5」強制重新整理瀏覽器網頁即可**。

## 📝 1. 新增訂單
1. 左側選單進入「新增訂單」。
2. 輸入客戶資料、期望出貨日期。
3. 點擊「+ 新增品項」，於彈出菜單選擇需要的產品。
4. **遇見秤重商品？** 沒關係！數量填上後，若無預估小計請保持留白，等實際備料出貨確認總重後，日後再至排單區填入最後數字！
5. 按下「確定儲存」會有一顆巨無霸讀取圓球（我們已確保它穩穩罩在所有人頭上不被遮擋），結束後就大功告成了。

## 🔍 2. 排單管理 (強大且靈活)
這是掌握每張單的指揮高塔。
1. **勾選單狀態**：直接從下拉選單隨手更換：備料中、製作中、已出貨。
2. **精準修改單量或金額**：點進「📝 查看明細」，可以從這邊把原本沒填的「秤重最後結帳大金額」補上去，或是如果客人變心想退掉這顆水餃，直接點擊旁邊的 🗑️刪除！
   *(不用擔心，如果您把整張訂單的所有明細都刪光了，系統也會貼心自動幫您把主單直接下架回收，不留痕跡！)*

## 📈 3. 營收統計 (精明的毛利推算器)
想知道這個月到底進帳多少？菜錢成本佔多少？
1. 選好起訖日期按下查詢！
2. 我們擁有**智能百分比轉換技術**：如果您今天在「菜單」把某道秤重商品的成本定為 `40%`。不論這顆肉您今天賣了 250 還是 700 塊，系統完全不會算錯本錢，它會精準的依照您「最後實際拿到的錢」抽出 40% 算出實成本！
3. **無/舊品項警示**：如果它在表格秀出這個警告，那就表示過去賣出的這道菜，在您現今的菜單上名字不小心被改掉，或者被加上了空白而認不出對方了。不過別擔心，為了保護財報完整，**它依然會幫您把賣出的數量與獲得之營收分毫不差的加總進總額中！**

## 🍔 4. 菜單與支出管理機制
- 無論是變換菜單單價、還是突然發現多報了一筆買菜錢支出，從現在開始您不用再辛苦回去登入打開密密麻麻的 Google 表格來修改。直接點下畫面的 **「修改」** 或 **「刪除」** 編輯，系統靠獨特的身份指紋 (UUID) 自動鎖定，精準把數字更新回 Google，完全防彈防呆！
